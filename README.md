# מסך בית הכנסת המאור

עמוד אינטרנט שפתוח כל הזמן על הטלוויזיה בבית הכנסת. מוצגים בו:
- שעון ותאריך עברי ולועזי, הפרשה, ראש חודש, חגים וצומות
- זמני היום לפי לוח חב"ד, זהים לזמנים באתר צעירי חב"ד לתל אביב
- זמני התפילות של היום (אחרי ערבית מוצגות כבר התפילות של מחר)
- הדלקת נרות וצאת שבת, וחגים שחלים בשבוע הקרוב
- מודעות שיעורים שמתחלפות כל 15 שניות
- פתגם היום יום
- שיעורי חת"ת ורמב"ם

## מה יש בתיקייה

| קובץ | תפקיד |
|---|---|
| `index.html` | המסך עצמו. את הכתובת שלו פותחים בטלוויזיה |
| `config.js` | **הגדרות**: זמני תפילות, כתובת, דקות להדלקת נרות |
| `data/announcements.json` | **מודעות השיעורים** |
| `data/daily.json` | תניא, רמב"ם ופתגם היום יום לפי תאריך |
| `js/zmanim.js` | חישוב הזמנים (אותה נוסחה כמו באתר צעירי חב"ד) |
| `js/learning.js` | חומש ותהלים של חת"ת |
| `js/sources.js` | משיכת היום יום, התניא והרמב"ם מהרשת |
| `js/app.js` | הלוגיקה של המסך |
| `preview.html` | קובץ אחד שכולל הכול, לתצוגה מקדימה במחשב |

## עדכון מודעות

בקובץ `data/announcements.json` כל מודעה נראית כך:

```json
{
  "kind": "שיעור שבועי",
  "title": "שיעור בתניא",
  "subtitle": "עם רב בית הכנסת",
  "when": "כל יום ראשון · 20:30",
  "where": "בבית הכנסת",
  "note": "כיבוד קל",
  "from": "2026-10-01",
  "until": "2026-12-31",
  "days": [0, 3]
}
```

רק השדה `title` הוא חובה. השדות `from` ו-`until` קובעים מאיזה תאריך ועד איזה תאריך המודעה מוצגת. השדה `days` מגביל אותה לימים מסוימים: 0 הוא ראשון ו-6 הוא שבת. המסך בודק כל 5 דקות אם יש מודעות חדשות.

## זמני תפילות

נקבעים בקובץ `config.js`. "מעוגל" פירושו תמיד עיגול כלפי מטה ל-5 דקות, כך ש-17:37 הופך ל-17:35.

| | מתי | איך מחושב |
|---|---|---|
| שחרית | ראשון עד שישי | 8:15 |
| מנחה מוקדמת | ראשון עד חמישי | 13:30 |
| מנחה | ראשון עד חמישי | 10 דקות לפני השקיעה, מעוגל |
| ערבית | ראשון עד חמישי | 35 דקות אחרי מנחה |
| מנחה | ערב שבת וערב חג | 10 דקות אחרי הדלקת נרות, מעוגל |
| קבלת שבת (בערב חג: ערבית) | ערב שבת וערב חג | 30 דקות אחרי מנחה |
| שחרית | שבת וחג | שעון חורף: 9:00 (בשבת מברכים 9:30). שעון קיץ: 9:30 (בשבת מברכים 10:00) |
| מנחה | שבת וחג | שעה ורבע לפני צאת השבת, מעוגל |
| ערבית | מוצאי שבת וחג | בצאת השבת, מעוגל |

שבת מברכים היא השבת האחרונה בחודש לפני ראש חודש (בין כ"ג לכ"ט בחודש), חוץ מאלול. המסך מזהה אותה, וגם את שעון החורף והקיץ, לבד.

## מקורות לתוכן היומי

המסך מושך את התוכן היומי לבד, ישירות מהטלוויזיה, בלי שרת ביניים:
- **פתגם היום יום:** מחב"דפדיה (chabadpedia.co.il), לפי התאריך העברי. בימים שבהם הפתגם המקורי כתוב ביידיש הוא מוצג ביידיש, כמו בחב"דפדיה. טקסט ארוך נגלל לאט.
- **תניא יומי ורמב"ם יומי (שלושה פרקים ופרק אחד):** מספריא (sefaria.org). בדקתי שהם תואמים ללוח של צעירי חב"ד.
- **חומש ותהלים:** מחושבים במסך עצמו.

התוכן נשמר בזיכרון של הטלוויזיה, כך שהוא נשאר על המסך גם אם האינטרנט נופל. אם רוצים לתקן משהו ידנית, כותבים אותו בקובץ `data/daily.json`, ומה שכתוב שם גובר על התוכן שנמשך מהרשת:

```json
{ "days": { "2026-10-06": { "tanya": "...", "rambam": "...", "hayomyom": "...", "chumash": "..." } } }
```

## בדיקה של יום אחר

מוסיפים לכתובת `?now=` ואחריו תאריך ושעה. לדוגמה, `index.html?now=2026-10-09T16:10` מציג את המסך כאילו עכשיו יום שישי ב-16:10.

## התקנה על הטלוויזיה

1. **מעלים את התיקייה לאתר חינמי** (GitHub Pages או Netlify) כדי לקבל כתובת קבועה.
2. **בטלוויזיה:** פותחים את הדפדפן, נכנסים לכתובת ושומרים אותה במועדפים. כדאי להפעיל מסך מלא.
3. **לוחצים פעם אחת על OK בשלט.** בחלק מהטלוויזיות הלחיצה הזו מפעילה את מצב "מסך דולק". נקודה ירוקה בפינה השמאלית התחתונה מראה שהמצב פעיל.
4. **מכבים בהגדרות הטלוויזיה את החיסכון בחשמל.** זה השלב החשוב ביותר, כי העמוד לא יכול לעקוף הגדרות של הטלוויזיה עצמה.
   - **סמסונג:** כיבוי אוטומטי (Auto Power Off) במצב כבוי; Eco Solution, חיסכון באנרגיה וזיהוי אי-פעילות במצב כבוי; שומר מסך (Screen Saver) במצב כבוי.
   - **LG:** כיבוי אוטומטי אחרי 4 שעות (Auto Off) במצב כבוי; Eco Mode במצב כבוי; שומר מסך במצב כבוי.
   - **אנדרואיד TV / גוגל TV:** Daydream או שומר מסך במצב "אף פעם"; מצב שינה במצב "אף פעם".

**אם הדפדפן של הטלוויזיה לא יציב** (נסגר או נכבה), הפתרון האמין ביותר הוא סטיק אנדרואיד זול (למשל Chromecast או Xiaomi TV Stick) עם האפליקציה Fully Kiosk Browser. היא פותחת את העמוד אוטומטית כשהטלוויזיה נדלקת ומשאירה אותו דולק תמיד.

## הגנות שכבר בנויות בעמוד

- **מניעת כיבוי:** העמוד משתמש ב-Wake Lock, ואם הדפדפן לא תומך בזה, בסרטון שקט ובלתי נראה שרץ בלולאה.
- **רענון לילי:** העמוד נטען מחדש כל לילה ב-3:30, כדי להישאר יציב לאורך זמן.
- **הגנה מצריבה:** כל 10 דקות המסך זז בכמה פיקסלים, כדי למנוע צריבה של התמונה.
- **עבודה בלי אינטרנט:** הזמנים מחושבים במסך עצמו. אם החיבור נופל, המסך ממשיך לעבוד עם המידע האחרון.
- **התאוששות מתקלה:** אם קורית תקלה, העמוד נטען מחדש לבד אחרי דקה.

## עוד לא מחובר

- **סוכן הוואטסאפ (חפציבה):** יקבל מודעות מהקבוצה ויעדכן את `data/announcements.json`.
- **חומש בשבוע שהשבת שלו היא חג:** במקום לנחש את סדר הלימוד, המסך מציג "יעודכן בהמשך". אפשר להשלים ידנית ב-`daily.json`.
